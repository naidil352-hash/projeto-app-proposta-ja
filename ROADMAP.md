# Roadmap

## Completed

- Phase 1: core commercial entities and import foundation.
- Phases 2.1-2.3: structure analysis, mapping, decisions and application.
- Phase 3.0: Learning Engine.
- Phase 3.1: Knowledge-to-Decision bridge.
- Phase 3.2: Commercial Context.
- Phase 3.3: Sales Intelligence.
- Phase 3.4: Action Planning.
- Phase 3.5: simulation-only Action Execution Core.
- Phase 3.6: simulation-only Communication Gateway.
- Phase 3.7: deterministic Message Intelligence and human review.
- Phase 3.8: controlled official WhatsApp Business Cloud API integration with fail-closed external effects.

## Not implemented

No campaign, broadcast, batch, scheduler, automatic follow-up, automatic reply, email, SMS, telephone or LLM integration is implemented. Any later scale or additional channel requires a separate phase and security review.
